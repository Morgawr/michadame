# Michadame Capture Comparison

I put together a comparison to see how the software handles the capture versus native emulation or PC releases. It is important to note that the color space isn't entirely accurate because I am using a cheap capture device. The hardware device captures at 1080p which is then upscaled to 4K, whereas the PC screenshots shown later are completely native 4K. Also, the Dreamcast is running through an S-Video connection instead of VGA, so the base output is already somewhat washed out before it even reaches the capture card.
